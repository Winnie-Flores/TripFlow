# 旅序 TripFlow

旅序是一个面向自由行的 Web 课程项目。把地图上的地点拖进每日行程，即可排序、跨天调整，并查看高德返回的道路、交通用时和预计到达时间。旅行记录保存在当前浏览器。

## 环境与启动

- Node.js 22.12 及以上的 22.x 版本，或 Node.js 24 及以上。npm 10 及以上。本次核对使用 Node.js 25.8.0 和 npm 11.11.0。
- 建议使用支持 WebGL 的现代桌面 Chrome 演示地图拖放。手机可切换行程与地图，并通过“安排”添加地点。
- 安装依赖需要访问 npm registry。底图、城市查询、地点搜索、道路和足迹地图需要访问高德服务。

在项目根目录执行：

```sh
npm ci
npm run dev
```

打开[当前规划](http://127.0.0.1:5173/#planner)或[旅行记录](http://127.0.0.1:5173/#records)。开发服务固定在 `127.0.0.1:5173`，端口被占用时会报错。无高德配置时可直接体验内置地点与拖拽。

## 本地地图配置

1. 在高德开放平台创建应用并添加 **Web 端（JS API）** Key，取得 Key 和配套安全密钥 `securityJsCode`。[高德开放平台](https://console.amap.com/)
2. 首次配置时在项目根目录运行 `cp .env.example .env.local`。已有 `.env.local` 时直接编辑其中的两项。
3. 按实际访问地址核对高德控制台的授权设置。修改配置后重启开发服务，生产预览则重新构建后启动。

```dotenv
VITE_AMAP_KEY=你的_Web_JS_API_Key
VITE_AMAP_SECURITY_JS_CODE=你的_securityJsCode
```

`.env.local` 已加入忽略规则。Vite 会将 `VITE_` 变量打包到前端，公开分发前需另行处理高德鉴权。[加载说明](https://lbs.amap.com/api/javascript-api-v2/guide/abc/load) · [安全密钥说明](https://lbs.amap.com/api/javascript-api-v2/guide/abc/jscode)

## 构建与检查

```sh
npm run lint
npm test
npm run build
npm run preview
```

构建输出到 `dist/`。生产预览地址为 [127.0.0.1:4173](http://127.0.0.1:4173/#planner)，预览端口也采用严格模式。开发与预览地址分别持有浏览器存档，迁移可用 JSON 导入导出。

## 使用方式

| 想做什么 | 操作 |
| --- | --- |
| 建立旅行 | 点“＋ 新增旅行”，填写名称、城市、开始日期和天数。旅行记录可打开已有行程。 |
| 安排地点 | 从右侧地图把标记拖到左侧某天或卡片间的插入位，也可点“安排”。武汉有 25 个精选地点，杭州有 24 个，其他城市可在线搜索。 |
| 调整行程 | 用卡片手柄排序或跨天移动。“编辑”内可填写停留时长、预约时间和备注。同地点多次到访按独立游览保存。 |
| 寻找与收藏 | 按景点街区、餐厅、购物和酒店筛选候选地点。可收藏地点、看已安排项，并编辑地图标记样式。 |
| 设置酒店 | 在“酒店住宿”搜索并加入候选，按天选择出发酒店与当晚入住，或设为全程酒店。当天入住会作为次日默认出发点。 |
| 查看道路与时间 | 展开“路线与交通”，按段选步行或驾车，并切换选中日或全部日期概览。设置当天出发时间后可展开“预计时间轴”，查看到达、等待、离开和预约冲突。 |
| 恢复编辑 | 顶部提供撤销与重做，最多保留 20 步。刷新、切换旅行或导入时开启新的编辑历史。 |
| 查看足迹 | 在“旅行记录”手动设置“已去过”或“规划中”，展开足迹地图。中国市域按状态填绿或橙，其他城市显示灰色。同城已去过优先。 |
| 保存、备份与分享 | 编辑自动保存在当前浏览器。JSON 用于备份与导入，同 ID 导入更新对应旅行。“导出可读行程”可下载离线 HTML，或用系统打印窗口保存 PDF。 |

如需在可读导出中包含各天已计算的交通，请先选“全部日期概览”并等待计算结束。

## 已知限制

- 项目采用纯前端和本地存储。记录依赖当前浏览器及访问源，清理站点数据会清除本机记录。上限为 50 次旅行、合集 4 MB、单份 JSON 2 MB。每次旅行最多 30 天、500 个地点和 3000 次游览。
- 每次旅行对应一个城市。道路提供步行和驾车，距离与用时取决于高德结果，交通用时与停留分别统计。路线失败的段落会明确标注，时间轴在缺交通时显示时间下限。
- 地点、酒店和预约用于行程规划。酒店页提供位置和行程设置，预约时间由用户填写。
- 无地图配置时进入演示模式。已配置但地图加载失败时，可选“切换到拖拽演示”。演示平面采用非地理比例的地点卡片，可操作拖放和编辑。在线搜索、地图底图、道路与市域填色需要联网。
- 足迹地图覆盖中国，以手动旅行状态和已确认的城市为准。同城多次旅行合并显示。
